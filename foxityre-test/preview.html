Tyre Size Guide

You can read the tyre size from the tyre sidewall, usually in the format 215/55 R17.

Width

The first number, such as 215, is tyre width in millimetres.

Profile

The second number, such as 55, is the sidewall profile percentage.

Rim Size

The R number, such as R17, is the rim size in inches.
